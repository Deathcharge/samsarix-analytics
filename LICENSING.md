# Licensing and attribution

Samsarix Analytics source code is licensed under the Mozilla Public License,
version 2.0 (`MPL-2.0`). The complete terms are in `LICENSE`.

## Why MPL-2.0

MPL-2.0 is a standard, OSI-approved, file-level copyleft license. It allows the
library to be used in open-source or proprietary larger applications, while
requiring distributed modifications to MPL-covered files to remain available
under MPL-2.0. It also includes contributor patent grants and requires license
notices to be preserved.

Primary references: the [Mozilla MPL 2.0 FAQ](https://www.mozilla.org/MPL/2.0/FAQ/)
and the [OSI license record](https://opensource.org/license/mpl-2.0).

That balance fits a reusable library better than the repository's previous
customized Business Source License: the old production-use threshold was hard
to interpret for an embedded metrics library, did not match the product name or
company, and made the package source-available rather than open source.
